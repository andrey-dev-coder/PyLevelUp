# PyLevelUp

Telegram-бот для подготовки к техническим собеседованиям по Python. Бот ежедневно прогоняет
пользователя через адаптивную сессию вопросов, выбранных алгоритмом интервального повторения,
и считает прогресс, точность и место в глобальном рейтинге.

Бот: [@pylevelup_bot](https://t.me/pylevelup_bot).

## Какую проблему решает

Подготовка к собесу по Python это в первую очередь насмотренность: знание стандартной библиотеки,
устройство языка, ловушки в наследовании, асинхронность, GIL, типичные системные вопросы про БД и
кэширование. Прочитать всё это за раз нельзя, забывается тоже быстро. PyLevelUp решает это через
ежедневную короткую сессию (до 50 вопросов) и интервальное повторение: бот сам подбирает, что
пора повторить, и не показывает то, что вы уже усвоили.

## Для кого

- Junior и Middle Python разработчики, которые готовятся к собеседованиям.
- Те, кому удобно учиться в формате коротких ежедневных сессий с напоминаниями.
- Те, кто хочет видеть прогресс и сравнивать себя с другими (стрик, точность, рейтинг).

## Ключевые фичи

- Алгоритм интервального повторения (адаптация SuperMemo-2).
- Лимит сессии 50 вопросов в день, 4-6 вариантов ответа в виде Inline-кнопок.
- Промежуточное состояние сессии и ответы хранятся в Redis. PostgreSQL принимает данные одним
  пакетом по завершении сессии или по таймауту, что радикально снижает нагрузку при частых
  кликах на кнопки.
- Глобальный рейтинг считается через оконные функции SQL и периодически пересчитывается фоновой
  задачей Celery.
- Ежедневные напоминания о тренировке через Celery Beat.
- Чистая модульная архитектура: routers, services, repositories.

## Стек

- Python 3.11.4
- aiogram 3.x
- PostgreSQL + SQLAlchemy 2.0 + Alembic, JSONB для вариантов ответа
- Redis (FSM, кэш сессии)
- Celery 5 + Redis или RabbitMQ как брокер
- Docker / docker-compose, Railway-ready

## Команды

- `/start` приветствие и регистрация в БД
- `/test` запуск ежедневной сессии (до 50 вопросов)
- `/stats` персональная статистика и место в рейтинге
- `/info` описание проекта и контакты автора
